## Раздел 2: Реализация логики (Services)

- [ ] **Задача 2.1:** Добавить ленивую загрузку предметов в `src/services/metaService.ts`
  * Создать функцию `requireHeroItems(heroId, cache)`, которая загружает популярность предметов по сети, если их нет в кэше, и сохраняет в файл.

- [ ] **Задача 2.2:** Реализовать логику получения предметов `/items` и `/bad_items`
  * Написать функцию `getItemsForPosition(position)` (топ предметов по стадиям для топ-героев).
  * Написать функцию `getBadItemsForPosition(position)` (неэффективные предметы на основе ролевых эвристик).

- [ ] **Задача 2.3:** Реализовать логику связок `/lane_combo` и `/game_combo`
  * Написать функцию `getLaneCombo(heroName)` (поиск синергичных напарников по роли линии).
  * Написать функцию `getGameCombo(heroName)` (поиск синергичных напарников по командным дракам/ультимейтам).

- [ ] **Задача 2.4:** Реализовать логику сводки по герою `/hero`
  * Написать функцию `getHeroSummary(heroName)` (винрейт, пикрейт, баны, роли, позиция, предметы, контрпики).
