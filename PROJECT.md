# Dota 2 Discord Bot

## Коротко

Проект: Discord-бот для Dota 2, который показывает актуальную мету и помогает принимать решения по пикам, героям, позициям и предметам.

Главная идея: бот должен не просто хранить статичную информацию, а регулярно обновлять данные из свежих источников, потому что мета Dota 2 часто меняется после патчей, микропатчей, турниров и изменений в пабликах.

## Что такое мета в контексте бота

Мета - это текущие сильные и слабые герои, предметы, роли, билды и игровые решения, которые лучше всего работают в актуальном патче и на выбранном уровне игры.

Бот должен уметь смотреть мету по позициям:

- Position 1: Carry / керри
- Position 2: Mid / мид
- Position 3: Offlane / оффлейн
- Position 4: Soft Support / семи-саппорт / четверка
- Position 5: Hard Support / фулл саппорт / пятерка

## Основные функции

### Мета героев по позициям

Бот должен показывать нынешнюю мету на каждую позицию:

- лучшие герои на керри
- лучшие герои на мид
- лучшие герои на оффлейн
- лучшие герои на четверку
- лучшие герои на пятерку

Для каждого героя желательно показывать:

- winrate
- pickrate
- banrate, если источник данных это позволяет
- изменение за последнее время
- уверенность данных, если выборка маленькая

### Худшие герои меты по позициям

Бот должен показывать худших героев текущей меты на каждую позицию:

- худшие керри
- худшие мидеры
- худшие оффлейнеры
- худшие четверки
- худшие пятерки

Важно: "худший герой" не обязательно означает просто самый низкий winrate. Нужно учитывать pickrate, количество матчей и роль героя. Герой с маленькой выборкой не должен случайно попадать в топ худших.

### Метовые предметы по позициям

Бот должен показывать лучшие предметы в текущей мете отдельно по позициям:

- лучшие предметы для керри
- лучшие предметы для мида
- лучшие предметы для оффлейна
- лучшие предметы для четверки
- лучшие предметы для пятерки

Для предметов желательно учитывать:

- частоту покупки
- winrate после покупки
- среднее время покупки
- позицию героя
- патч
- стадию игры: early / mid / late

### Худшие предметы по позициям

Бот должен показывать худшие или неэффективные предметы в текущей мете по позициям:

- плохие предметы для керри
- плохие предметы для мида
- плохие предметы для оффлейна
- плохие предметы для четверки
- плохие предметы для пятерки

Важно: не считать предмет плохим только по низкому winrate. Нужно учитывать ситуацию: некоторые предметы часто покупаются в проигранных играх как desperate item.

### Контрпики героев

Бот должен уметь показывать по 3 контрпика против каждого героя на каждой позиции.

Пример:

Если враги пикнули Anti-Mage, бот должен уметь показать:

- 3 контрпика с позиции керри
- 3 контрпика с позиции мида
- 3 контрпика с позиции оффлейна
- 3 контрпика с позиции четверки
- 3 контрпика с позиции пятерки

То есть команда должна отвечать не просто "кто контрит Anti-Mage вообще", а "кто лучше всего контрит Anti-Mage именно с нужной позиции".

Контрпики должны считаться по нескольким факторам:

- winrate героя против выбранного героя
- lane matchup, если данные доступны
- роль и позиция героя
- популярность героя в текущем патче
- способность реально выполнять роль на выбранной позиции

### Хорошие связки героев

Бот должен уметь показывать хорошие связки героев:

- связки для линии
- связки по игре после лайнинга
- связки под конкретную позицию
- связки под уже выбранного героя
- связки против конкретного вражеского пика, если данные позволяют

Связки на линию должны помогать понять, какие два героя хорошо стоят вместе. Например:

- carry + hard support
- offlane + soft support
- mid + активный support, если нужен роум или помощь рунами

Связки по игре должны учитывать не только линию, но и общую синергию героев:

- комбинации способностей
- общий темп игры
- teamfight-потенциал
- пуш
- сейв
- инициация
- контроль
- магический или физический burst
- способность закрывать слабости друг друга

Пример:

Если игрок выбрал Juggernaut, бот должен уметь предложить хороших саппортов на линию и героев, которые хорошо играют с ним по всей игре.

Для связок желательно показывать:

- почему герои хорошо сочетаются
- winrate пары, если источник данных это позволяет
- количество матчей в выборке
- подходит ли связка для текущего патча
- насколько связка сложная в исполнении

## Возможные Discord-команды

- `/meta` - общая текущая мета
- `/meta position:carry` - мета по конкретной позиции
- `/worst position:mid` - худшие герои по позиции
- `/items position:offlane` - метовые предметы по позиции
- `/bad_items position:support4` - худшие предметы по позиции
- `/counter hero:Anti-Mage position:mid` - 3 контрпика против героя с выбранной позиции
- `/counter hero:Anti-Mage` - контрпики против героя по всем 5 позициям
- `/synergy hero:Juggernaut` - хорошие связки с выбранным героем
- `/lane_combo hero:Juggernaut position:carry` - хорошие герои на линию к выбранному герою
- `/game_combo hero:Juggernaut` - хорошие герои для общей игры после лайнинга
- `/hero hero:Anti-Mage` - сводка по герою
- `/patch` - текущий патч и дата последнего обновления данных

## Обновление данных

Бот должен сам обновлять информацию в фоне, а не ждать команды пользователя.

Базовая схема:

1. Фоновый процесс регулярно получает свежие данные из API.
2. Данные нормализуются по героям, ролям, предметам и патчу.
3. Результаты сохраняются в базу данных или кэш.
4. Discord-команды показывают уже подготовленные свежие данные.

На старте можно обновлять данные раз в 30-60 минут. Позже можно сделать разные интервалы:

- часто обновлять матчи и тренды
- реже обновлять справочники героев/предметов
- отдельно проверять выход новых патчей

## Возможные источники данных

Потенциальные источники:

- OpenDota API
- Steam Web API
- STRATZ API
- DatDota
- Liquipedia или другие источники для турнирного контекста

Для первой версии лучше начать с OpenDota, потому что это простой и доступный источник. Если данных по ролям, предметам или контрпикам будет недостаточно, можно добавить STRATZ или другой источник.

## Важные решения на будущее

- На каком ранге считать мету: all ranks, Ancient+, Divine+, Immortal?
- Отдельно ли считать профессиональную мету и паблик-мету?
- Как определять позицию героя в матче?
- Как считать силу связки: по winrate пары, частоте пары, синергии способностей или смешанной оценке?
- Разделять ли связки для линии и связки для всей игры?
- Какой минимальный размер выборки нужен, чтобы герой или предмет попадал в рейтинг?
- Как учитывать свежий патч, если данных по нему еще мало?
- Нужны ли уведомления в Discord, если герой резко вырос или упал в мете?

## Первый MVP

Минимальная полезная версия:

1. Discord-бот запускается и отвечает на команды.
2. Есть фоновое обновление данных.
3. Есть команда `/meta`, которая показывает лучших героев по 5 позициям.
4. Есть команда `/worst`, которая показывает худших героев по 5 позициям.
5. Есть команда `/counter`, которая показывает по 3 контрпика против выбранного героя на каждой позиции.
6. Есть команда `/synergy`, которая показывает хорошие связки для выбранного героя.
7. В ответах показывается дата и время последнего обновления данных.
